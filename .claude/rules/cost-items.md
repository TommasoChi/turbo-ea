# Cost items: the cost of an Application / IT Component is a standard object

> Loaded when you touch the cost-items services, routes, models, migrations 175/176 or the Costs section (full list in the frontmatter). Fork-only file: upstream never edits it.

- **For Application and IT Component the cost is a sum of catalogue items per fiscal year, never typed.** `card_costs` holds one row per `(card_id, fiscal_year)` with `items` JSONB `{item_key: {amount, renewal_date}}`; the catalogue is `cost_item_types` (stable `key`, label + flat `{locale: str}` translations, `archived`; never deleted, key never renamed, reserved names refused). The type list is one constant per side: `COST_ITEM_TYPES` (`card_costs.py`, `frontend/src/lib/costItems.ts`). Initiative and Provider keep their `cost` fields and `card_cost_history`.
- **TCO has one definition (`card_costs.py`: `year_costs` / `resolve_year`); the report, the section and the derived copy all use it.** Archived items count. A year with a row (even an empty one) is confirmed; only the CURRENT year with no row falls back to the latest earlier row (renewal dates shifted, `confirmed=false`), never the Forecast or a past year. Window: the section shows `current-4 … current+1`, writes accept `current-5 … current+1` (PUT only; DELETE of an absent key is a no-op).
- **`attributes.costTotalAnnual` is a derived, read-only copy written by `recompute_derived`, ABSENT when the card has no cost lines.** Every writer of `attributes` for these types calls it (card create/update, platform import, ServiceNow, workspace apply, `recalculate_and_rescore`, the daily rollover loop, saving the fiscal-year start); it runs BEFORE the calculations; a Calculation cannot target it; a value sent by a client or an import is overwritten, and the platform importer ignores it in its diff. Never write it directly.
- **Reads and writes are gated per card: view = `costs.view` OR any stakeholder on the card (`can_view_costs`); edit = `costs.edit` OR a stakeholder role with `card.edit` on THAT card (`can_edit_costs`).** App-level `inventory.edit` alone does not edit costs; a hidden card is 404. `costs.view` defaults are unchanged; `costs.edit` defaults to admin only. The Costs section follows the server's `can_edit`.
- **Cost writes publish `card.costs_updated` (item keys only, never amounts or dates) and are not rollbackable.** Amounts reach nobody without cost access: every event feed (card history, dashboards, admin dashboard, `/events`, my-cards, mutation-batch events, SSE) goes through `cost_event_redaction.redact_cost_events` — add any new feed to it. Writes lock the year row (`FOR UPDATE`) and the service never commits.
- **Migration 175 preserves each card's TCO per year; the years where it changes are listed in `app_settings.general_settings["cost_items_migration_report"]` (capped).** It also strips the old breakdown keys from `cards.attributes`; the legacy keys stay in `all_cost_keys` so old event diffs stay redacted.
